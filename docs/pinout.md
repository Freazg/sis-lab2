# Pinout і схема підключення стенда ЛР2

**Проєкт:** Motion-Mirroring Teleoperator (тема 6, Додаток A). **Форма:** B (Wokwi).
**Плата:** NUCLEO-C031C6 (MB1717), MCU STM32C031C6T6, корпус LQFP48.
Схема в симуляторі — [`diagram.json`](../diagram.json); вона відповідає цій таблиці рядок у рядок.
У прошивці всі номери пінів, AF і хендли живуть в одному файлі — [`firmware/Platform/board.h`](../firmware/Platform/board.h).

| Пристрій | Лінія | Робочий режим | Піковий режим | Джерело цифр |
|---|---|---|---|---|
| STM32C031C6 @ 48 МГц (HSI48) | 3V3 | 3.40 мА typ (без периферії) | 4.90 мА max (125 °C) + периферія | [DS] Table 28 p.45 |
| MPU-6050 (гіро + акселерометр) | 3V3 | 3.8 мА | 3.9 мА (з DMP) | [PS] §6.3 p.14 |
| GY-521: LDO + LED живлення модуля | 3V3 | ~1…3 мА (оцінка, виміряти) | — | — |
| W25Q64JV | 3V3 | 10 мкА standby, 8 мА читання | **25 мА** програмування/стирання | [W25] §9.4 p.61 |
| LED ×2 (330 Ω) | 3V3 через GPIO | (3.3 − 2.0) / 330 ≈ 4 мА кожен | 8 мА обидва | розрахунок; ≤ 20 мА на пін [DS] Table 22 |
| FT232RL | USB ПК (не Nucleo) | 15 мА | — | [FT] Table 5.2 p.18 |
| SG92R ×2 | **окреме 5 В** | виробник не публікує | виробник не публікує; для мікросерво 9 г типово сотні мА при старті/застопорюванні | [SG] |
| **Сума на 3V3 Nucleo** | | ≈ 20 мА | ≈ 45 мА | |

**Лінія 3V3 Nucleo:** LDO U6 LDL112PV33R, сумарне споживання плати й шилдів < 500 мА ([UM] §6.5.2 p.14). Пікові ~45 мА — це менше 10 % ліміту, запас понад 450 мА.

**Чому серво живляться окремо.** USB ST-LINK дає 500 мА на всю плату ([UM] Table 7 p.13). Два SG92R у момент старту або застопорювання споживають порівнянний струм. Просідання 5V_USB перезапускало б МК і викликало б струм через світлодіоди захисту USB (LD2, [UM] §6.10). Тому живлення серво — окреме джерело 5 В (≥ 2 А), **земля спільна** з GND Nucleo, бо ШІМ відраховується від GND МК. Індуктивне навантаження двигунів не повинно бути на лінії 3V3, від якої живляться МК, IMU і флеш.

## 4. Параметри шин і розрахунок від дерева тактування

Дерево тактування ([RM] Figure 9 p.123): HSI48 → HSIDIV = 1 → SYSCLK = 48 МГц → AHB /1 → HCLK 48 МГц → APB /1 → **PCLK = 48 МГц**. Flash: 1 wait state для HCLK ≤ 48 МГц ([RM] Table 14 p.59). fPCLK ≤ 48 МГц ([DS] Table 24 p.42).

| Шина | Тактування периферії | Налаштування | Розрахунок | Результат | Межі |
|---|---|---|---|---|---|
| I2C1 | I2C1SEL = 00 → I2CCLK = PCLK = 48 МГц ([RM] §6.4.20) | Fast-mode, TIMINGR = **0x50330309** | PRESC = 5 → tPRESC = 6/48 МГц = 125 нс; SCLL = 9 → tSCLL = 10·125 = 1.25 мкс; SCLH = 3 → tSCLH = 4·125 = 0.5 мкс; SDADEL = 3 (375 нс), SCLDEL = 3 (500 нс) | tSCL ≈ 2.5 мкс → **400 кГц** ([RM] Table 115 p.711) | Fm: tLOW ≥ 1.3 мкс, tHIGH ≥ 0.6 мкс ([RM] Table 112 p.700); I2CCLK ≥ 9 МГц ([DS] Table 60 p.76); MPU-6050 до 400 кГц ([PS] §6.7 p.18) |
| SPI1 | PCLK = 48 МГц | Master, mode 0 (CPOL = 0, CPHA = 0), 8 біт, MSB first, BR = 011 (÷16) | 48 МГц / 16 | **3 МГц** | C031 master ≤ 24 МГц ([DS] Table 62 p.77); W25Q64 03h ≤ 50 МГц ([W25] §9.6 p.63); mode 0 підтримується ([W25] p.11) |
| USART2 / USART1 | USARTxSEL = 00 → PCLK | 115200 8N1, OVER8 = 0 | USARTDIV = 48·10⁶ / 115200 = 416.67 → BRR = 417 | 115107.9 бод (**−0.08 %**) | USARTDIV ≥ 16 ([RM] §26.5.7 p.763) |
| TIM3 | TIMPCLK = PCLK (APB ÷1) ([RM] §6.2.11 p.128) | PSC = 47, ARR = 19999, PWM1, CCR = мкс | 48 МГц / 48 = 1 МГц (1 тік = 1 мкс); (19999 + 1) · 1 мкс | **20 мс = 50 Гц**, роздільність 1 мкс ≈ 0.097° | SG92R dead band 1 мкс ([SG]) |

**Чому 3 МГц для SPI, а не 24 МГц.** Логічний аналізатор методички (fx2lafw, 24 MS/s) має мати щонайменше 4–8 вибірок на біт, тобто SCK ≤ 3–6 МГц. Пропускна здатність 3 МГц — 375 КБ/с, а запис траєкторії за PRD (50 Гц × кілька байт) потребує < 1 КБ/с.

**Чому I²C Fast-mode.** FR-01 PRD — читання 14 байт IMU з частотою 200 Гц. Пакетне читання займає 153 біти: при 100 кГц це 1.53 мс (31 % часу шини), при 400 кГц — 0.38 мс (8 %).

**Pull-up на I²C.** Внутрішні pull-up МК вимкнені. Працюють резистори модуля GY-521 до його VCC, тому модуль живиться від 3V3, щоб лінії не підтягувалися до 5 В. Номінал перевірити мультиметром. Для Fm: tr ≤ 300 нс ([I2C] Table 10), Rp(max) = tr / (0.8473 · Cb) = 300 нс / (0.8473 · 50 пФ) ≈ 7.1 кОм. Rp(min) = (VDD − VOL) / IOL = (3.3 − 0.4) / 3 мА ≈ 1 кОм ([I2C] §7.1). Кілька модулів зі своїми pull-up з'єднуються паралельно, і сумарний опір падає (наприклад, 4.7 кОм ∥ 4.7 кОм = 2.35 кОм), тож при додаванні GY-89 зайві резистори треба зняти.

## 7. Інструкція зі складання стенда (для людини, яка не займалась монтажем)

1. **Без живлення.** На Nucleo перевірити перемички: JP5 = [1-2] (живлення від ST-LINK), JP6 (IDD) встановлена ([UM] Table 4).
2. **GY-521:** VCC → 3V3 (CN6-4), GND → GND, SCL → D15, SDA → D14. AD0 лишити непідключеним (на модулі він підтягнутий до GND, адреса 0x68).
3. **W25Q64:** VCC(8) → 3V3, GND(4) → GND, /WP(3) і /HOLD(7) → 3V3, CLK(6) → D3, DI(5) → D11, DO(2) → D12, /CS(1) → D10. **Не подавати 5 В.**
4. **FT232RL:** перемичку VCCIO поставити в 3.3 В. RXD → D1, TXD → D0, GND → GND. Живлення модуля — від USB ПК.
5. **LED:** D7 → 330 Ω → анод зеленого LED → катод → GND; D4 → 330 Ω → анод червоного → GND.
6. **Серво:** сигнальні дроти: pan → D5, tilt → D6. Червоний (+) обох — на **окреме** джерело 5 В, коричневий (−) — на GND цього джерела, яке **з'єднати з GND Nucleo**.
7. **Логічний аналізатор:** GND аналізатора → GND Nucleo (без спільної землі вимір безглуздий: рівні рахуються відносно іншої землі, і наводки дають фантомні фронти). Канали — як у таблиці §1 (`docs/captures/*.diagram.json` для кожного запису).
8. Увімкнути USB. В UART (115200 8N1) має з'явитися самоперевірка `ST,dev=SUMMARY,res=PASS,pass=9,fail=0`.

## 9. Що не можна перевірити в симуляторі і як перевірити на залізі

| Аспект | Чому не перевіряється в Wokwi | Як перевірити на реальному стенді |
|---|---|---|
| Таймінги I²C Fast-mode | модель I²C STM32C0 у Wokwi завжди дає SCL = 100 кГц (5/5 мкс) незалежно від TIMINGR (аномалія A4) | записати SCL/SDA Saleae (≥ 4 MS/s), виміряти tLOW ≥ 1.3 мкс і tHIGH ≥ 0.6 мкс; фронти tr ≤ 300 нс — осцилографом |
| Repeated START, TXDR preload | не підтримуються моделлю (A2, A3) | прошивка `make build-nucleo` використовує HAL_I2C_Mem_Read; на записі має бути Sr замість P+S |
| Номінали pull-up, час наростання | у симуляторі ідеальні фронти | мультиметр (опір SCL/SDA → 3V3 при вимкненому живленні), осцилограф |
| Струми, просідання живлення, перешкоди від серво | живлення не моделюється | амперметр на JP6 (IDD МК), USB-тестер, осцилограф на 3V3 і 5 В при старті серво |
| Реальний W25Q64 (tPP, tSE, BUSY) | модель за datasheet з типовими часами | вимір часу між 02h і BUSY=0 за записом; має вкладатися в tPP max 3 мс |
| SG92R: кут за імпульсом | виробник не дає таблиці; модель Wokwi ідеальна | калібрування транспортиром: імпульси для 0°/90°/180° |
| B1 на MB1717 | у Wokwi кнопка намальована окремо | натиснути B1, перевірити `MODE,HOLD` |
