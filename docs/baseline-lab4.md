# Базова лінія для ЛР4

У ЛР4 ті самі сценарії повторюються на FreeRTOS тим самим методом. Змінюється лише архітектура прошивки: стенд, частоти, UART і формат логів лишаються.

Прошивка: `ab3dcf9e`, 48 МГц, UART 115200, SPI 3 МГц, Wokwi, вимірювальний код увімкнено.

## Як відтворити

```bash
make image build chips
make scenarios
make metrics
make mem
```

Потрібен токен Wokwi у `~/.wokwi_token`. Сценарії лежать у `docs/metrics/scenarios/`, випадкові моменти натискань задані фіксованим зерном `SEED = 3` у `tools/run_scenarios.py`. Вільний план Wokwi CI дає 50 хв на 30 днів і 5 хв на сесію, тому повний прогін краще робити один раз на чистій збірці.

| Сценарій | Що відбувається | Тривалість симуляції | Підключення |
|---|---|---|---|
| `s1` | HOLD, лише періодичні задачі | 10 с | стенд + щупи |
| `s2` | REC, рух, `status` раз на 2 с | 45 с | те саме |
| `s3` | 40 циклів: `dump`, 3 × `status`, рух, кнопка | ≈ 60 с | те саме |
| `sc1-erase`, `sc1-dump` | довга операція і періодична задача | 6 с, 15 с | те саме |
| `sc2-btn-idle`, `sc2-btn-long` | 50 натискань без і під час `dump` | 12 с, 25 с | те саме |
| `sc3-flood` | 168 байт команд під час `dump`, 10 разів | 10 с | без щупів |
| `sc4-fault` | сенсор від'єднано, потім SDA на землі | 8 с | кнопки в SDA, SCL і SDA → GND |
| `sc5-break` | частота IMU 200…1000 Гц, по 3 с | 40 с | без щупів |
| `sc7-boot` | старт, сенсор з'являється через 300 і 1000 мс | 4 с | кнопки в SDA, SCL |
| `sc8-powerloss` | обрив запису сторінки, перевірка CRC | 6 с | без щупів |
| `fr02`…`fr09` | перевірки PRD | 1…130 с | див. `SCENARIOS` |
| `long` (`tools/long_run.py`) | 7 циклів REC + PLAY, понад годину, без руху | 4300 с | VS Code, порт 4000 |

## Вимірювальний інструментарій

Без змін переноситься в ЛР4:

- **Команди прошивки:** `stats`, `stats reset`, `mem`, `evt`, `perfcal`, `rate <hz>`, `fault powerloss`, `reset`.
- **Формати логів:** `STAT name= n= min_us= avg_us= max_us=`, `JITTER`, `LOAD`, `CNT`, `HIST`, `STACK`, `EVT t_us= name=`. Перший рядок логу містить git-хеш: `BOOT,fw=,git=,board=`.
- **Лічильник часу:** `platform_cycles()` на SysTick, 48 МГц. У ЛР4 тік FreeRTOS теж іде від SysTick, тому джерело часу треба перевірити першим (`perfcal`, поле `backward=0`).
- **Службові GPIO:** PA0 P_IMU, PA1 P_PWM, PA4 P_LONG, PB1 P_REACT, PA9 MARK.
- **Логічний аналізатор:** Wokwi, 8 каналів, VCD з роздільністю 1 нс. Щупи задає `SCENARIOS` у `tools/run_scenarios.py`.
- **Хост-скрипти:** `tools/run_scenarios.py`, `tools/analyze_metrics.py` (логи + VCD + декодер timing), `tools/mem_report.py`, `tools/long_run.py`, `tools/plot_lr3.py`.
